# 🌍 World Happiness Analysis Using SQL

## 📌 Project Overview

This project analyzes the World Happiness Report data from 2016 to 2019 using MySQL. It explores happiness scores across countries and years to identify trends and compare factors related to happiness, including GDP per capita, social support, healthy life expectancy, freedom, and generosity.

## 🎯 Objectives

- Analyze happiness scores across different countries and years.
- Identify countries with the highest happiness scores.
- Calculate yearly average, maximum, and minimum happiness scores.
- Compare happiness scores between different years.
- Explore the relationship between happiness and related socio-economic indicators.
- Practice SQL queries for data analysis.

## 📂 Dataset

The dataset contains four yearly CSV files:

- `happiness_2016`
- `happiness_2017`
- `happiness_2018`
- `happiness_2019`

The datasets were imported into MySQL and combined into a single table named `happiness_all_years` using `UNION ALL`.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **Query Editor:** MySQL Workbench
- **Language:** SQL
- **Dataset Source:** Kaggle – World Happiness Report datasets

## 🧠 SQL Concepts Used

- `SELECT` and `WHERE`
- `ORDER BY` and `LIMIT`
- `BETWEEN` and `DISTINCT`
- Aggregate functions: `AVG()`, `MAX()`, `MIN()`, `COUNT()`
- `GROUP BY` and `HAVING`
- `INNER JOIN` and `LEFT JOIN`
- Subqueries

- Calculated columns and score comparisons
